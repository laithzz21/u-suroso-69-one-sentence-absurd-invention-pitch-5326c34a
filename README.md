## The entry

> A toaster that ejects burnt toast with a tiny parachute and a pre-written apology note addressed to your smoke alarm, which has suffered enough.

The tiny annoyance is burnt toast setting off the smoke alarm. The fix is absurdly over-engineered: instead of preventing the burn, the toaster stages a rescue mission — a parachute for the toast, and a formal apology to the real victim in the room, the long-suffering smoke alarm.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (one sentence, 1–220 characters) and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), then verifies the written file by reading it back.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is written to `entry.txt` in the output directory.
